# Projeto

Portfolio interativo experimental baseado em um aquário digital.

# Objetivo

Criar um website cinematográfico onde peixes nadam pelo aquário e funcionam como navegação do portfolio.

Cada peixe representa uma seção:

* About
* Projetos
* Contato
* Experimentos

# Stack

* Next.js
* TypeScript
* React Three Fiber
* Three.js
* TailwindCSS
* GSAP

# Direção visual

* sofisticado
* cinematográfico
* minimalista
* dark
* HUD futurista
* instalação digital

# Regras

* evitar UI genérica
* evitar componentes padrão
* manter código simples
* explicar partes complexas
* foco em motion design
* foco em performance

# Estrutura

* components/
* systems/
* shaders/
* hooks/
* scenes/

# Sistema dos peixes

Os peixes devem:

* nadar lentamente
* mudar direção suavemente
* possuir tracking box
* reagir ao hover
* funcionar como navegação

# Importante

O usuário está aprendendo Three.js.
Explique conceitos difíceis de forma simples.
